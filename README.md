# Vaporex

App web local para organizar clientes, notas y próximos pasos.

## Uso

Abre `index.html` en un navegador moderno. No requiere instalación, servidor ni conexión a una cuenta. Los cambios se guardan en el almacenamiento local del navegador en el dispositivo actual.

## Incluye

- Alta, edición y eliminación de fichas de clientes.
- Búsqueda por nombre, empresa o correo y filtro por estado.
- Notas y recordatorios con fecha, estado de completado y aviso de vencimiento.
- Resumen de clientes y vista de próximos pasos.
- Datos de ejemplo editables para empezar.

## Datos

La información se almacena en `localStorage` y no se sincroniza con otros dispositivos. Borrar los datos del sitio en el navegador también eliminará las fichas guardadas.
